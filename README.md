# Lab 1.1 – Variables, Expressions, and Arrays

In this lab, you will practice using variables, arithmetic expressions, type conversion, C-style arrays, loops, and output.

Write all of your code inside `main`. Do not write any additional functions.

## Requirements

1. Declare and initialize two integer variables with the values `10` and `4`.

2. Declare and initialize a `double` variable with the value `5.5`.

3. Declare a constant integer with the value `5`. Use this constant as the size of a C-style integer array.

4. Using the two integer variables, store the following results in the five elements of the array:

   * the sum of the two values
   * the product of the two values
   * the result of integer division of 10 by 4
   * the remainder when 10 is divided by 4
   * twice the sum of the two integer values

5. Use a `for` loop to print each element of the array on a separate line.

6. Declare an integer variable. Assign the `double` value to this integer variable and print the resulting value.
